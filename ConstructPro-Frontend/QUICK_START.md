# Quick Start Guide

## Installation

```bash
cd CPMS/constructpro-frontend
npm install
```

## Run Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Backend Setup

Make sure your .NET backend is running:
```
https://localhost:7001
```
